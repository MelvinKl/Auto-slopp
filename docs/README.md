## About Arc 42

Arc 42 is a template for documenting software and system architecture. It provides a structured approach to capturing architectural decisions, design rationale, and system context.

## About Auto-slopp

Auto-slopp is a Python-based automation framework for task execution with a pluggable worker system. It processes tasks from various sources (GitHub issues, Vikunja tasks, etc.) using configurable AI-powered CLI tools.
